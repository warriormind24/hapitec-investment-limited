# Hapitec Investment Limited

Official web application for **Hapitec Investment Limited** — Zambia's trusted partner in piggery, agriculture, construction, and materials supply based in Copperbelt Province.

## 🚀 Features

- **Responsive Mobile Navigation**: Clean, accessible navigation drawer with keyboard and overlay support.
- **Service Showcase**: Detailed breakdown of livestock production, construction, and supply consultancy.
- **Dynamic Gallery & Awards**: Image lightbox modal with zoom and view options for project showcase and awards.
- **Quote Request System**: Interactive contact and quote request modal.
- **Modern Build Setup**: Fast local development and bundling powered by Vite.

## 🛠️ Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)

### Development Commands

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start dev server**:
   ```bash
   npm run dev
   ```

3. **Build for production**:
   ```bash
   npm run build
   ```

4. **Preview production build**:
   ```bash
   npm run preview
   ```

5. **Format code**:
   ```bash
   npm run format
   ```
